# User Service - Merezh

Микросервис, отвечающий за хранение и управление пользователями.

## 📋 Обзор

User Service - это микросервис на Spring Boot, который предоставляет функциональность управления пользователями: регистрацию, получение, валидацию учётных данных и удаление. Используется внутри системы Auth Service для аутентификации и другими сервисами через Gateway.

Сервис **не занимается аутентификацией сам** - он только хранит данные пользователей и предоставляет эндпоинт валидации, который использует Auth Service.

## 🚀 Технологический стек

**Backend**

- Java 21 - основной язык
- Spring Boot 3 - фреймворк приложения
- Spring Data JPA - доступ к БД и ORM
- Spring Security Crypto - BCrypt для хэширования паролей

**База данных**

- PostgreSQL - основная БД

**DevOps**

- Docker - контейнеризация
- Docker Compose - оркестрация нескольких контейнеров
- Spring Boot Actuator - healthcheck и мониторинг

**Тестирование**

- JUnit 5
- Mockito

## ✨ Возможности

### 👤 Управление пользователями

- Создание нового пользователя
- Получение пользователя по ID
- Получение всех пользователей (только admin, через Gateway)
- Удаление пользователя по ID
- Валидация учётных данных (внутренний, используется Auth Service)

### 🔐 Безопасность

- Пароли хранятся в виде BCrypt-хэшей (хэширование выполняется в Auth Service)
- Защита эндпоинтов реализована на уровне Gateway (JWT + роли)
- Сервис доверяет заголовкам `X-User-Id` и `X-User-Role`, которые устанавливает Gateway
- Внутренние эндпоинты (`/create`, `/validate`) не публикуются через Gateway

### ✅ Валидация данных

- Формат и уникальность email
- Уникальность логина
- Единый формат ошибок через `@RestControllerAdvice`

## 📚 Эндпоинты API

Базовый путь: `/api/v1/users`

| Метод  | Эндпоинт    | Описание                      | Доступ      |
|--------|-------------|-------------------------------|-------------|
| GET    | `/`         | Получить всех пользователей   | ADMIN       |
| GET    | `/{id}`     | Получить пользователя по ID   | ADMIN       |
| POST   | `/create`   | Создать нового пользователя   | authservice |
| POST   | `/validate` | Валидировать учётные данные   | authservice |
| DELETE | `/{id}`     | Удалить пользователя по ID    | ADMIN       |

**Примечание:** Сервис доверяет данным от Gateway.

## 📦 Структура проекта

```
src/main/java/ru/merezh/userservice/
├── config/                    # Конфигурация Spring (PasswordEncoder и т.д.)
├── controller/                # REST-контроллеры
├── dto/                       # Data Transfer Objects
├── entity/                    # JPA-сущности
│   └── enums/                 # Enum Role
├── exception/                 # Кастомные исключения и обработчики
│   ├── controller/            # @RestControllerAdvice
│   └── dto/                   # DTO для ответов с ошибками
├── repository/                # Spring Data JPA репозитории
└── service/                   # Бизнес-логика
```

## 🔒 Безопасность

Пароли хранятся в виде BCrypt-хэшей. Хэширование выполняется в Auth Service до создания пользователя здесь.

## 🩺 Health Checks

Сервис предоставляет эндпоинты Spring Boot Actuator:

| Эндпоинт                       | Назначение                   |
|--------------------------------|------------------------------|
| `/actuator/health`             | Общий статус                 |
| `/actuator/health/liveness`    | Liveness probe               |
| `/actuator/health/readiness`   | Readiness probe (включая БД) |
| `/actuator/info`               | Информация о сервисе         |

## 🧪 Тестирование

```bash
mvn test
```

Unit-тесты покрывают основные сценарии `UserService`:

- Создание пользователя с занятым email → исключение
- Создание пользователя с занятым логином → исключение
- Создание пользователя с валидными данными → сохранение
